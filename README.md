## Описание проекта 
Проект представляет собой 2D-игру в жанре survival-RPG с видом сверху.
Основная механика игры строится на исследовании игрового мира, сборе ресурсов и управлении инвентарем. 
Реализована система ограниченного инвентаря с возможностью стакинга (объединения одинаковых предметов), 
выброса предметов и использования топора для рубки деревьв.

## Стек проекта 
* **Игровой движок / Платформа:** Godot Engine 
* **Язык программирования:** GDScript

## Что было использовано в проекте 
* **Узлы (Nodes):** Area2D, CanvasLayer, CharacterBody2D и другие
* **Паттерны / Подходы:** Глобальный код (Global.gd), Сигналы (Signals) 
* **Ресурсы:** находятся в папке проекта в папке assets
